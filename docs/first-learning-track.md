# First learning track: Build a simple personal webpage

## Audience and outcome

- **Audience:** Indonesian learners who are new to web development and can use a web browser and a code editor. No programming experience is assumed.
- **Measurable outcome:** by the end of the track, a learner can build a one-page personal profile using semantic HTML and responsive CSS, run it locally, and verify it against a short checklist on both a narrow and a wide viewport.
- **Estimated effort:** four lessons of 20–30 minutes, plus a 45–60 minute capstone. These are estimates to validate with learners, not promises about completion time.

## Sequence

1. **Create the page structure.** Introduce files, HTML elements, headings, paragraphs, and links. Lab: make a profile page with a name, introduction, and one useful link.
2. **Make content meaningful.** Use semantic sections, lists, and accessible link text. Lab: add an interests list and a clearly labeled contact link; check heading order and keyboard navigation.
3. **Style and adapt the page.** Introduce CSS selectors, spacing, color contrast, and a small-screen-first layout. Lab: create a readable profile card that works at 375px and 1280px wide.
4. **Review and improve.** Practice browser inspection, fixing a broken link or layout issue, and writing a short project description. Lab: use the provided checklist to find and fix at least two issues.

## Capstone

Build a one-page personal profile with a short introduction, at least two content sections, one working link, and a responsive layout. A learner completes it when all of these are true:

- the page opens locally without a build/runtime error;
- the document has one descriptive page title and a sensible heading hierarchy;
- the link works and has understandable text;
- content remains readable without horizontal scrolling at 375px and 1280px viewport widths;
- the learner can explain one change they made after using the review checklist.

## Starter files and checks

- A minimal `index.html` and `styles.css`, plus a completed example, are available from the learning-track page.
- Each lesson states prerequisites, the expected result, and a self-check before introducing new concepts.
- Keep this track free to read and runnable locally; do not require an account or collect learner progress for the first release.
- Validate clarity with a small beginner pilot before publishing the track as available.

## Release status

The first release is published at `/learn/first-web-page` with four lessons, labs, downloadable starter files, a completed example, and a capstone checklist. It remains free to use without an account and does not collect progress data.
